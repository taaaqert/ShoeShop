# 🥿 ShoeShop — Магазин обуви (C# / .NET 8)

Простое консольное приложение — имитация магазина обуви. Демонстрирует работу с Git, GitHub и базовыми структурами C#.

## 📋 Описание

Приложение `ShoeShop` позволяет:
- просматривать каталог обуви (бренд, модель, размер, цена, остаток);
- добавлять обувь в корзину с учётом наличия на складе;
- просматривать корзину и итоговую сумму;
- удалять товар из корзины (с возвратом на склад);
- очищать корзину целиком.

Данные хранятся в памяти — при перезапуске всё сбрасывается. Никаких БД и внешних зависимостей.

## 🚀 Запуск

Требуется [.NET SDK 8.0+](https://dotnet.microsoft.com/download).

```bash
# клонировать
git clone https://github.com/ТВОЙ_ЛОГИН/ShoeShop.git
cd ShoeShop

# запустить
dotnet run
